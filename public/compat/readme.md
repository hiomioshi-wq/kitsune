# The Lantern Courier's Delivery Notes

`README`s. Kitsune should render it as a document, not a wall of `#` signs.

- Headings of every size
- A paragraph with **bold**, *italic* and `code`
- A [relative link](rem.html) and an [absolute link](https://example.org/)
- An image with a relative path: ![a sample page](/sample/000.svg)
